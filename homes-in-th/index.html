Overview

Homes in TH is a responsive real estate platform designed to support different user types through a public website, a user dashboard, and an internal back-office system.

As a UX/UI Designer, I designed responsive interfaces across the platform, contributed to the design system, collaborated with developers, and helped shape the overall user experience throughout the project.

Key challenges

01

Designing for multiple user groups

Creating a consistent experience across the public website, user dashboard and internal back-office system while addressing different user needs.

02

Building a scalable design system

Creating reusable foundations and components, which later grew into the Homnect24 design system.

03

Balancing client requirements with UX

Turning business requirements into practical user experiences while keeping the platform easy to use and visually unified.

My responsibilities

  • Created user flows for key journeys across the platform
  • Designed responsive interfaces for the public website, user dashboard and back office
  • Built and maintained reusable components in the design system
  • Designed email templates, empty states and error pages
  • Turned business requirements into practical design solutions with the team
  • Collaborated with developers through implementation and handoff
  • Reviewed design work and gave feedback to interns and graphic designers new to UX/UI
  • Ran visual QA so builds matched the intended experience across devices

Design system

This project introduced the first version of the design system, with reusable foundations and components shared across the platform. It was later expanded and refined as the foundation for the Homnect24 design system.

Final solution

Three connected parts: a public website to discover properties, a dashboard for users to manage their activity, and a back office for the team running the platform.

PUBLIC WEBSITE

Home

Introduces the platform and helps users discover properties through a clean and structured layout.

Property search

Eight ways to search, each opening as a focused modal from the homepage: location, train line, travel time, road, car, drawn area, developer and tag.

Listing & map

Browse properties through both list and interactive map views.

Property detail

Presents property information, images and key details in a clear, easy-to-read layout.

Compare

Compare multiple properties side by side before making decisions.

Forum & news

Articles, discussions and updates about the real estate market.

USER DASHBOARD

My dashboard

An overview of user activities and account information.

Notifications

Keeps users informed about updates and important activities.

My package

Manage subscriptions and package details.

Property inquiry

Track inquiries and communication history for interested properties.

My profile

Manage personal information, account settings and preferences in one place.

BACK OFFICE

Subscription

Manage subscription plans and customer packages.

Customer

Manage customer information and account details.

Property

Manage property listings and related information.

Payment transactions

Review and manage payment records and transaction history.

MOBILE

Responsive screens

Key pages adapt to mobile with a bottom navigation bar, keeping search, listings, articles and account tools easy to reach with one hand.

Collaboration

I collaborated closely with fellow designers to maintain consistency across the platform, worked with the team during project discussions, and partnered with developers throughout implementation. I also reviewed design work and gave feedback to interns and graphic designers new to UX/UI to help maintain quality across the team.

Reflection

Working in a larger design team taught me how to align ideas across designers.

I learned to turn business requirements into practical solutions and keep a shared design system consistent. This project also became the foundation for the design system that was later expanded in Homnect24.
